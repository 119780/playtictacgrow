TicTacGrow — Changelog
======================
Version 1.2.0


Timer
- Made 4 lengths of timer (1, 5, 10, unlimited)
- Made ranked matches use 10 minute default
- Forced 10 minutes when toggling ranked
- Changed leaderboard logic for future multiple leaderboards

Drawing
- Added the ability to call for a draw
- 30s interval for draw-calling
- Opponent accepting added
- Added "Opponent has offered draw" notification

Spectators
- Friends can spectate their friends
- Added spectate button in the friends list
- Spectators can watch the game but cannot place anything

See the 3-in-a-row
- Added an ending that draws a line through the winning 3 in a row
